# TakaLeaf — notes for Claude Code

Personal income/expense tracker in BDT. Version 1 = .NET 10 backend + React web app; version 2 adds
an offline-first Android app (React Native) that syncs with the same API.
**Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) before changing behaviour**: it has the
architecture, the data model and the rules below in full. For any UI work also read
[PRODUCT.md](PRODUCT.md) (who it is for, principles) and [DESIGN.md](DESIGN.md) (the visual system;
machine-readable sidecar in `.impeccable/design.json`). Requirements, UI/UX, plan and testing plan
are in [docs/](docs/).

## Commands

```bash
docker compose -f deploy/docker-compose.dev.yml up -d   # PostgreSQL 18, Mailpit :8025, Seq :5341
dotnet run --project backend/TakaLeaf.App               # API on http://localhost:5080
dotnet test backend/TakaLeaf.App.Tests                  # backend tests (needs the dev PostgreSQL)
pnpm install && pnpm dev                                # web on http://localhost:5173, /api proxied
pnpm typecheck && pnpm test && pnpm build               # web + shared checks (same as CI)
docker build -t takaleaf .                              # production image (web + API on :8080)
pnpm --filter @takaleaf/e2e e2e                         # browser + accessibility tests (E2E_BASE_URL, E2E_MAILPIT_URL)
```

## Rules that must not break

- **Money is `long` poisha** (C#) / safe integer (TS). Never decimal, double or float for amounts.
  Format with `Money.Format` / `formatBdt`; parse typed taka with `parseTaka`.
- **Balances are calculated** from opening balance + transactions (`Common/Balances.cs`). Never store one.
- **Local days and months** come from `LocalCalendar` (Asia/Dhaka); store UTC.
- **Soft delete only**: set `DeletedAt`; every user table inherits `SyncedEntity`. Always `SaveChangesAsync`.
- **Scope every query by `UserId`**. Another user's row → 404 via `NotFound.Problem`; another user's id
  inside a request → 400 "does not exist".
- **Errors** are problem responses; field errors via `ValidationErrors.For(field, "Plain sentence.")`.
- Fee rows (`FeeOfId`) and loan rows (`PersonId`) change only through their owner, not `/transactions`.

## Backend conventions

- One project, `backend/TakaLeaf.App`, vertical slices: `Features/<Feature>/<Action>.cs` holds the
  endpoint, its records and its handler. Shared rules for a feature go in `<Feature>Models.cs`
  (`internal static class <Feature>Rules`). No repositories, services or MediatR.
- Register a new feature group in `Program.cs` (`api.Map<Feature>()`).
- `TreatWarningsAsErrors` is on. Nullable is on.
- **Migrations are generated by CI**, not by hand: change entities/`ModelConfiguration.cs`, then commit
  `backend/.migration-request` containing the migration name (e.g. `AddTags`) and push the branch.
  The `EF migration` workflow adds the migration and commits it. Then `git pull`. Never edit
  files in `Data/Migrations/`.
- Tests: every endpoint through HTTP (`AuthClient.SignedInClient()`, `WalletTests.Create`,
  `TransactionTests.Add`...), each test with fresh users, `[Collection(DatabaseCollection.Name)]`.
  Include an "another account cannot…" test for anything user-owned.

## Web conventions

- `apps/web/src`: `api/` (client, queries, types), `pages/<area>/`, `ui/` primitives, `layout/`.
- Server data only through TanStack Query hooks in `api/queries.ts`; money mutations call
  `useInvalidateMoney`. Types in `api/types.ts` mirror the C# DTOs (camelCase, enums as strings).
- Tailwind with the brand CSS variables in `index.css` (`--tl-*`, `bg-forest`, `text-expense`…);
  surfaces use the `glass` class. Must work at 390 px wide with no sideways scroll, and in dark theme.
- Labels on every field (`TextField`, `SelectField`, `AmountField`), errors next to the field.
- Tests with `fakeApi` + `renderApp` in `src/test/`; assert the request body that was sent.

## Workflow

- Branch from `main` (`m<N>/<topic>` or `fix/<topic>`), small commits, open a PR, wait for CI
  (web, backend, Docker image), squash-merge. The repo owner has allowed Claude to push, open PRs
  and merge them.
- UI copy is short, plain English; amounts like `৳1,25,000.00`.
- Keep docs current: `docs/ARCHITECTURE.md` when a rule, table or endpoint changes; `DESIGN.md`
  (and `.impeccable/design.json`) when a colour, type style or component changes;
  `docs/REQUIREMENTS.md` and `docs/DEVELOPMENT-PLAN.md` status when a feature ships.
