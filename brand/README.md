# TakaLeaf brand assets

Brand: TakaLeaf - "Your Money. Your Control."
Logo: concept C, "T Leaf" - a geometric letter T with a leaf in its upper structure. Redrawn as vector paths from the brand identity board.

- logo/      mark (colour, on-dark, mono) and horizontal + vertical logos with tagline, SVG + PNG. Text is outlined Inter, so no font is needed.
- android/   copy the mipmap-* folders into app/src/main/res/. Adaptive icon (foreground, background, monochrome) plus legacy and round icons.
- web/       favicon.ico, favicon.svg, PNG icons (green and white tile), apple-touch-icon and manifest.webmanifest.
- splash/    1080x1920 light and dark splash screens, SVG + PNG.
- tokens/    brand palette, light and dark theme colours, glass, type, radius and spacing as JSON and CSS variables.
- source/    SVG sources the icons were rendered from.

Palette: Forest Green #0F7A44 (primary), Leaf Green #22A06B (secondary), Sage Green #83CFA2 (accent), Light Green #E7F5EC (background),
White #FFFFFF (surface), Slate Gray #64748B, Muted Gray #94A3B8, Border #D1DFD8. Typeface: Inter (SIL Open Font License).
